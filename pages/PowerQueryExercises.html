Power Query Exercises

Fifteen messy-data problems in four phases, covering most of the Transform ribbon. Download the workbook, try each one in Power Query, then check your result here.

All names and numbers in the workbook are synthetic. Each sheet is numbered to match its exercise. In the M code, Source means the table already loaded from that sheet.

Today = Date.From(DateTime.LocalNow()),
// Today - [DateOfBirth] returns a duration, so work out completed years instead
Age = Table.AddColumn(Source, "Age", each let Y = Date.Year(Today) - Date.Year([DateOfBirth]) in if Date.AddYears([DateOfBirth], Y) > Today then Y - 1 else Y, Int64.Type),
Retire = Table.AddColumn(Age, "Retirement", each Date.AddYears([DateOfBirth], 60)),
Service = Table.AddColumn(Retire, "Service Years (approx)", each Duration.Days(Today - [DateOfJoining]) / 365.25)
